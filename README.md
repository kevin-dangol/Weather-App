# Weather-App

A weather app made usign flutter & Open weather app's api.

## Features
- Real time weather info
- Automatic location detection
- Animated weather display

## How to use
- Go to [Release](https://github.com/kevin-dangol/Weather-App/releases)
- Download the latest .apk
- Install it on ur device or emulator
